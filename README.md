# Team Directory App

A React + Vite application for browsing team members, viewing member details, filtering favorites, and switching between light and dark mode.

## Features

- Home landing page with summary metrics
- Users directory with responsive card grid
- Search by name, email, company, and role
- Favorites toggle and favorite count in the navbar
- Route-based user detail view
- Dark mode / light mode toggle
- Loading state and friendly error handling
- 404 Not Found page

## Technologies

- React
- Vite
- React Router DOM
- Tailwind CSS
- JavaScript

## Installation

1. Install dependencies:
   npm install

2. Start the development server:
   npm run dev

3. Build for production:
   npm run build

## Run locally

Open the local URL shown in the terminal after running the dev server, typically:

http://localhost:5173/

## Notes

- The project uses local sample data only.
- No API or database is required.
- Generated build output and node_modules are not included in version control.
